# Phanira — Next.js direct conversion

This project is a direct Next.js/App Router reconstruction of the approved Phanira landing-page reference supplied in chat.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes
- The supplied screenshot is treated as the visual source of truth.
- Extracted reference crops are used for the large photographic sections so the first pass remains visually close.
- All text, cards, navigation, sections and responsive behavior are real HTML/CSS and editable.
- Replace the reference crops with original full-resolution source imagery later for production-quality output.
